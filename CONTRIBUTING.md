# Contributing

## Adding a pattern

Every new pattern should contain:

1. Recognition signals
2. Core idea
3. Invariant
4. Original visual when useful
5. Generic C++17 template
6. Solving checklist
7. Complexity
8. Common mistakes
9. When not to use it
10. Representative practice problems

## Copyright rule

Do not add scanned textbook pages, copied figures, long textbook passages, or copied exercise sets. Create original explanations, examples, and diagrams.

## Quality rule

A pattern page should teach the reader how to recognize and reason about a technique, not just provide code.
