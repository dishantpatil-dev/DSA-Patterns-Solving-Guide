# 🎥 DSA Video Learning Resources

Use these videos **after reading the pattern notes and before solving the practice problems**. The repository keeps the videos as optional external learning resources; the written notes remain self-contained.

## Recommended channels

- **NeetCode** — pattern-focused interview explanations and visual problem walkthroughs: https://www.youtube.com/@NeetCode
- **take U forward (Striver)** — structured A2Z DSA coverage and placement-oriented problem solving: https://www.youtube.com/@takeUforward
- **Abdul Bari** — algorithm theory, correctness, complexity and classical DSA: https://www.youtube.com/@abdul_bari
- **Aditya Verma** — especially useful for sliding window, recursion/backtracking, stacks and DP: https://www.youtube.com/@TheAdityaVerma
- **WilliamFiset** — deeper data structures and graph algorithms: https://www.youtube.com/@WilliamFiset

## 🧠 How to use the videos

**1. Read the pattern → 2. Watch only if the idea is unclear → 3. Close the video → 4. Implement from memory → 5. Solve 2–3 new problems → 6. Return to the animation/dry run.**

Don't turn the repository into a video-watching checklist. The goal is **pattern recognition + independent problem solving**.

### Resource selection

The resource choices are intentionally split by purpose:

- **NeetCode:** concise, interview-oriented pattern/problem explanations.
- **Striver:** broad structured DSA coverage.
- **Abdul Bari:** deeper algorithmic theory and "why".
- **Aditya Verma:** strong pattern intuition for several recurring techniques.
- **WilliamFiset:** useful for deeper graph/data-structure study.

These links point to external YouTube content and may change over time.
