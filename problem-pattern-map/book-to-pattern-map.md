# Book → Pattern Map

This map is a study-oriented translation of the supplied DataStructures.pdf into reusable interview patterns.

| Book area | What to extract | Pattern practice |
|---|---|---|
| Algorithm analysis | growth, running time, recurrences | complexity analysis |
| Lists | ADTs, list operations | pointer manipulation |
| Stacks | LIFO behavior, recursion use | stack, monotonic stack |
| Queues | FIFO behavior, algorithm design | BFS, sliding structures |
| Search trees | ordered search | BST, tree DFS |
| Hashing | fast lookup and applications | frequency, complement, grouping |
| Priority queues | repeated minimum/priority extraction | heap, Top-K, greedy |
| Sorting | ordering algorithms and analysis | sort + scan, greedy |
| Disjoint sets | union/find and connectivity | DSU, Kruskal |
| Graph algorithms | representation and standard algorithms | DFS, BFS, shortest path, MST, topo |
| Algorithm design | common problem-solving techniques | greedy, divide & conquer, DP, backtracking |
| Amortized analysis | sequence-level cost reasoning | advanced analysis |
| Advanced structures | specialized trees/heaps | extension study |

## How to study from the book

1. Read the relevant source chapter.
2. Close the book.
3. Write the pattern in your own words.
4. Draw the state/invariant.
5. Implement the generic C++ template.
6. Solve unseen problems.
7. Record the mistake if the first attempt fails.

This repository is deliberately a **study layer over the textbook**, not a replacement or copy.
